# Proyecto de aplicacion web con Análisis de Anuncios de Venta de Vehículos 🚗

Este proyecto es una aplicación web interactiva desarrollada con Streamlit como parte del Sprint 7 del bootcamp de TripleTen, enfocado en herramientas de desarrollo de software. Se utilizó un dataset de anuncios de venta de vehículos en EE.UU. para realizar un análisis exploratorio de datos.

La aplicación permite explorar el dataset visualmente mediante dos gráficos interactivos: un histograma que muestra la distribución del odómetro de los vehículos, y un gráfico de dispersión que relaciona el kilometraje con el precio de venta. Cada gráfico se activa mediante una casilla de verificación.

Las tecnologías utilizadas son Python, Pandas, Plotly Express y Streamlit. La aplicación está desplegada en Render 

## Tecnologías utilizadas
- Python
- Pandas
- Plotly Express
- Streamlit
